# Карта AI-инициатив: производительность × ценность для клиента

Интерактивная карта из 160 AI-инициатив. По горизонтали — влияние на производительность компании, по вертикали — влияние на ценность для клиента.

Карта помогает отличать оптимизацию внутренних операций от инициатив, которые меняют ценность для клиента. Отдельно выделены две зоны расхождения:

- **Эффект только внутри** — процесс стал быстрее или дешевле, клиент этого не замечает.
- **Ценность за счёт компании** — клиент выигрывает, а внутренние метрики стоят на месте или ухудшаются.

Координаты — экспертная гипотеза о реалистичном эффекте, а не измеренные результаты.

## Возможности

- Фильтры по категориям, ролям, этапам цикла разработки и избранному, поиск.
- Карточка инициативы: описание, роли, оценки, разброс прогонов Монте-Карло, источник и уровень доказанности.
- Переход между активными инициативами: кнопки в карточке или клавиши ← →, 4 6.
- Избранное сохраняется в браузере (localStorage).

## Языки

Интерфейс и весь контент доступны на русском, английском, французском и польском. Язык задаётся переключателем в шапке или GET-параметром: `?lang=en`, `?lang=fr`, `?lang=pl`, `?lang=ru`. По умолчанию русский.

Русский остаётся базовым языком данных. Переводы инициатив лежат в объекте `TR` (по индексу строки: название, описание, комментарий, источник), термины — в `TERM`, строки интерфейса — в `UI`. Если перевода нет, показывается русский вариант.

## Как добавить инициативу

Все данные лежат в `index.html`, в массиве `data`. Формат строки:

```js
[название, категория, X, Y, [роли], описание, комментарий]
```

- Название — до 40 символов, описание — до 160.
- Роли — только из списка `ROLES`.
- Комментарий обязателен для категорий «Внутренний вау-эффект» и «Ценность за счёт компании».
- Для IT-инициатив заполняется `META[название]`: этап цикла (из `STAGES`), зрелость, доказанность, источник.

## Метод оценки

Для каждой оси задано треугольное распределение вокруг экспертной оценки. Ширина зависит от категории и зрелости практики: зрелая ×0,6, обычная ×1,0, хайповая ×1,4. Сид генератора — md5 от названия инициативы, поэтому результат воспроизводим. Прогонов 10, итог — среднее, округлённое до 0,1. Все прогоны хранятся в объекте `MC`.
